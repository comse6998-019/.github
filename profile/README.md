# COMS 6998-019: Design of Production Agentic Systems

*Columbia University · Fall 2026*

An agent is a system: a model proposes work, a runtime executes it through tools,
state connects the steps, and the infrastructure underneath fails. This course
treats agents as a systems-engineering problem rather than a prompting problem —
teams build one security-alert triage agent across the semester, and each unit adds
a constraint that forces a redesign: token budgets, tool contracts and MCP,
dependency-aware concurrency, context compaction and durable checkpoints, and
deployment on Kubernetes with measured recovery.
